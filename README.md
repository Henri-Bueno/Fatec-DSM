# Fatec DSM

Arquivo acadêmico da graduação em Desenvolvimento de Software Multiplataforma (DSM) na Fatec. Este repositório reúne materiais, exercícios, atividades e projetos desenvolvidos ao longo da graduação.

## Estrutura do repositório


Semestres com conteúdo disponível:

- [DSM 1](./dsm-1)
- [DSM 2](./dsm-2)

A organização segue a estrutura:

```text
Fatec-DSM
|-- semestre
	|-- disciplina
		`-- aulas / atividades / projetos / demais conteúdos
```

Novos semestres poderão ser adicionados à medida que houver conteúdo correspondente, mantendo essa mesma organização.

## Como utilizar este repositório

O repositório pode ser clonado normalmente com Git:

```bash
git clone https://github.com/Henri-Bueno/Fatec-DSM.git
```

Para consultar apenas um semestre, navegue diretamente para a pasta correspondente pelo GitHub. Os links dos READMEs permitem seguir da página principal para o semestre, para a disciplina e, depois, para as aulas, atividades ou projetos disponíveis.
